Comparative Study of Non-Invasive Anemia Detection: RGB Analysis of Anterior Conjunctiva Versus CIELAB Features from Palm Images using Artificial Neural Networks



The research work carried out a comparison study on the two methods of non-invasive anemia detection. This paper presents a technical comparison of the Anterior conjunctiva’s RGB analysis and the method that uses the CIELAB features of the palm image with an artificial neural network.



Methods



The first method calculated the RGB values of the anterior conjunctiva of the eye with the use of images collected. The data was classified into two classes of anemia using a binary artificial neural network. The second method used the CIELAB color space to obtain the color features of the palm image. The L, A, and B values were extracted and used to train the same ANN model deployed in the first method.



Results



The accuracy of the two methods was compared and reported in Table 1 below.



Method Accuracy (%)



Conjunctiva RGB 81



CIELAB 93



On comparison, it was observed that the CIELAB method had a higher accuracy than the RGB method. As a result, the CIELAB method is recommended for non-invasive anemia screening.
